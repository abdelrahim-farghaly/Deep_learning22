CH12 · SAFETY RULES

قواعد السلامة وتوليد الوقائع

كيف يتحوّل الكشف الخام إلى واقعة لها معنى وقرار

الكشف وحده ليس واقعة. كشف no_helmet في إطار واحد قد يكون خطأً في الـ Model أو لحظة عابرة. دور SafetyRuleEngine أن يقرّر متى يصبح هذا الكشف واقعة تستحق المراجعة، ومنع التكرار، وتحديد الخطورة والدليل.

12.1 من الكشف الخام إلى الواقعة

نتتبّع رحلة واحدة: الـ Model يُخرج كشفاً خاماً ← يُطبَّع إلى Detection (الفصل 10) ← تُقيّمه القواعد مقابل عتبات وتأكيد زمني ← يُنتَج IncidentCandidate ← يُحفظ كواقعة مع دليل. هذا التسلسل يفصل "ماذا رأى الـ Model" عن "ما الذي يستحق أن يُسجَّل"، وهو قرار قواعد لا قرار شبكة عصبية.

12.3 عتبات الثقة والتأكيد الزمني

لكل نوع عتبته الخاصة (PPE_CONF_THRESHOLD و FIRE_CONF_THRESHOLD و SMOKE_CONF_THRESHOLD). ولا يكفي تجاوز العتبة مرة واحدة: يجب أن يتكرّر الكشف لعدد إطارات متتالية (INCIDENT_CONFIRM_FRAMES) قبل توليد الواقعة. هذا "التأكيد الزمني" يقلّل الإنذارات الكاذبة الناتجة عن إطار شاذ واحد.

12.4 منع التكرار وفترات التهدئة

بعد توليد واقعة لنفس المسار (track_id) والنوع، نمنع توليد واقعة مكرّرة خلال فترة INCIDENT_COOLDOWN_SECONDS. المفتاح المستخدم في التتبّع الداخلي هو زوج (النوع، track_id)، فيصبح لكل عامل مسار واحد بدل عشرات الوقائع المتطابقة.

12.5 الربط بالـ Tracking ووقت البداية والنهاية

نربط الواقعة بالمسار عبر track_id، فيكون لدينا بداية (started_at_seconds) عند أول كشف مؤكَّد، ونهاية (ended_at_seconds) عند آخر كشف مؤكَّد للمسار نفسه. هذا يعطي الواقعة مدة واضحة، ويسمح بعرض المقطع الصحيح للمراجع.

12.6 قواعد معدات الوقاية (PPE)

إذا ظهر صنف no_helmet أو no_vest بثقة تتجاوز عتبة الـ PPE واستمرّ لعدد كافٍ من الإطارات، نولّد واقعة من نوع ppe_violation. نربطها بمسار الشخص إن وُجد، وإلا نكتفي بالصندوق والإطار.

12.7 قواعد الحرائق والدخان

صُنفا fire و smoke يُولّدان واقعة fire_smoke. لأن هذه الأحداث أخطر وأسرع، نستخدم عتبة مستقلة لكل صنف، ونعتبر ظهورهما بأعلى خطورة مقارنةً بمخالفات الـ PPE.

12.8 قواعد الاقتراب من المعدات: تقريب بالبكسل لا مسافة حقيقية

نقارن صندوق الشخص بصندوق المعدة أو بمنطقة خطر معرّفة (DANGER_ZONE_CONFIG) ونحسب نسبة تداخل (PROXIMITY_MIN_OVERLAP). إذا تجاوزت النسبة الحدّ، نولّد واقعة machine_proximity.

لا نتحدّث بالأمتار

هذا القياس تقريبي بالبكسل وليس مسافة حقيقية. بدون معايرة كاميرا (calibration) وبدون معرفة ارتفاع الكاميرا وزاوية المنظور، لا يمكن تحويل البكسل إلى متر. لذلك لا نكتب أبداً "المسافة 0.8 متر"، بل "تداخل بنسبة 18% من مساحة الصندوق". المعايرة تحسين مستقبلي لا جزء من الـ MVP.

12.9 تصنيف الخطورة واختيار الدليل

جدول 12-2: اقتراح تصنيف الخطورة (قابل للضبط من الإعدادات)
النوعالخطورة المقترحةملاحظة
fire_smokehighيُرفع إلى critical عند استمرار الحدث

الدليل هو صورة الإطار الذي تأكّدت فيه الواقعة، وتُحفظ بنوع image. نختار الإطار صاحب أعلى ثقة ضمن نافذة التأكيد، لا الإطار الأول فقط، ليكون الدليل أوضح للمراجع.

12.10 مثال عملي: واقعة مُولَّدة من عدّة إطارات

ليكن INCIDENT_CONFIRM_FRAMES=3 و INCIDENT_COOLDOWN_SECONDS=30، ولنتبع شخصاً بمسار track_id=7 بلا خوذة. الجدول يوضّح قرار القاعدة في كل إطار.

12.11 لماذا لا يتحوّل إطار واحد غير مؤكَّد إلى مخالفة خطيرة مؤكَّدة

لأن خطأ إطار واحد وارد في أي Model. لو اعتبرنا كل كشف واقعة مؤكَّدة، لغرق مسؤول السلامة في إنذارات كاذبة وفقد الثقة في النظام. لذلك نفصل بين ثلاث درجات: كشف خام (قد يكون خطأً)، وواقعة detected (تحتاج تأكيداً زمنياً)، وواقعة confirmed (بعد مراجعة بشرية فقط، الفصل 13). النظام لا يعلن "مخالفة خطيرة مؤكَّدة" من تلقاء نفسه أبداً.

# backend/app/ai/rules.py
from dataclasses import dataclass
from app.ai.base import Detection
from app.core.config import settings


@dataclass
class IncidentCandidate:
    incident_type: str
    severity: str
    class_name: str
    confidence: float
    frame_number: int
    started_at_seconds: float
    ended_at_seconds: float | None
    track_id: int | None
    zone_name: str | None
    detection_count: int
    summary: str


def overlap_ratio(a, b) -> float:
    """Fraction of box b covered by box a (pixel-based, approximate)."""
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b
    ix1, iy1 = max(ax1, bx1), max(ay1, by1)
    ix2, iy2 = min(ax2, bx2), min(ay2, by2)
    if ix2 <= ix1 or iy2 <= iy1:
        return 0.0
    inter = (ix2 - ix1) * (iy2 - iy1)
    area_b = (bx2 - bx1) * (by2 - by1)
    return inter / area_b if area_b else 0.0


class SafetyRuleEngine:
    """Turns raw detections into incident candidates."""

    def __init__(self) -> None:
        self._hits: dict[tuple, int] = {}
        self._last: dict[tuple, float] = {}

    def evaluate(self, detections: list[Detection]) -> list[IncidentCandidate]:
        out: list[IncidentCandidate] = []
        for det in detections:
            rule = self._classify(det.class_name)
            if rule is None or det.confidence < self._threshold(det.class_name):
                continue
            key = (rule, det.track_id)
            self._hits[key] = self._hits.get(key, 0) + 1
            if self._hits[key] < settings.INCIDENT_CONFIRM_FRAMES:
                continue  # not enough evidence yet
            if det.timestamp_seconds - self._last.get(key, -1e9) < settings.INCIDENT_COOLDOWN_SECONDS:
                continue  # cooldown to avoid duplicates
            self._last[key] = det.timestamp_seconds
            hits = self._hits[key]
            self._hits[key] = 0
            out.append(self._build(det, rule, hits))
        return out

    def _classify(self, name: str) -> str | None:
        if name in ("no_helmet", "no_vest"):
            return "ppe_violation"
        if name in ("fire", "smoke"):
            return "fire_smoke"
        return None

    def _threshold(self, name: str) -> float:
        if name in ("no_helmet", "no_vest"):
            return settings.PPE_CONF_THRESHOLD
        if name == "fire":
            return settings.FIRE_CONF_THRESHOLD
        if name == "smoke":
            return settings.SMOKE_CONF_THRESHOLD
        return settings.DETECTION_CONF_THRESHOLD

    def _build(self, det, rule, hits) -> IncidentCandidate:
        severity = "high" if rule == "fire_smoke" else "medium"
        return IncidentCandidate(
            incident_type=rule, severity=severity, class_name=det.class_name,
            confidence=det.confidence, frame_number=det.frame_number,
            started_at_seconds=det.timestamp_seconds, ended_at_seconds=det.timestamp_seconds,
            track_id=det.track_id, zone_name=None, detection_count=hits,
            summary=f"{rule} detected as {det.class_name}")

# backend/app/services/incident_service.py (excerpt)
from sqlalchemy.orm import Session
from app.ai.rules import IncidentCandidate
from app.models.enums import (
    EvidenceKind, IncidentSeverity, IncidentStatus, IncidentType)
from app.models.evidence import Evidence
from app.models.incident import Incident
from app.services.storage_service import save_evidence_image


class IncidentService:
    """Persists incident candidates and their evidence."""

    def __init__(self, db: Session) -> None:
        self.db = db

    def persist(self, job, candidate: IncidentCandidate, frame) -> Incident:
        incident = Incident(
            video_id=job.video_id, job_id=job.id,
            incident_type=IncidentType(candidate.incident_type),
            severity=IncidentSeverity(candidate.severity),
            status=IncidentStatus.detected,
            started_at_seconds=candidate.started_at_seconds,
            ended_at_seconds=candidate.ended_at_seconds,
            frame_number=candidate.frame_number, track_id=candidate.track_id,
            confidence=candidate.confidence, class_name=candidate.class_name,
            zone_name=candidate.zone_name, summary=candidate.summary,
            detection_count=candidate.detection_count)
        self.db.add(incident)
        self.db.flush()  # obtain incident.id for the evidence row
        key = save_evidence_image(frame, incident.id, candidate.frame_number)
        self.db.add(Evidence(
            incident_id=incident.id, kind=EvidenceKind.image, storage_key=key,
            content_type="image/jpeg", frame_number=candidate.frame_number,
            timestamp_seconds=candidate.started_at_seconds))
        self.db.commit()
        return incident
خلاصة الفصل 12

ما تعلّمناه

كيف تتحوّل الكشوفات الخام إلى وقائع عبر عتبات وتأكيد زمني ومنع تكرار، وكيف نصنّف الخطورة ونختار الدليل، ولماذا الاقتراب تقريب بالبكسل لا مسافة بالأمتار.

ما يجب تنفيذه

  • كتابة app/ai/rules.py بقواعد PPE والحرائق والاقتراب.
  • كتابة incident_service.py لحفظ الواقعة والدليل.
  • ضبط INCIDENT_CONFIRM_FRAMES و INCIDENT_COOLDOWN_SECONDS و PROXIMITY_MIN_OVERLAP.

المخرجات المتوقعة

  • واقعة بحالة detected لها بداية ونهاية ودليل صورة.
  • لا وقائع مكرّرة لنفس المسار داخل فترة التهدئة.

كيف نتحقق من الإنجاز

  • كشف واحد في إطار واحد لا يُولّد واقعة.
  • ثلاثة كشوفات متتالية تُولّد واقعة واحدة.
  • لا يوجد أي نصّ يذكر مسافة بالأمتار.

أخطاء شائعة

  • توليد واقعة من كل كشف فيُغرق النظام بالتكرار.
  • إعلان حالة confirmed آلياً بدل تركها للمراجعة.
  • تحويل نسبة التداخل إلى مسافة بالأمتار دون معايرة.
  • استخدام عتبة عامة واحدة لكل الأنواع.
