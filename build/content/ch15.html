CH15 · DASHBOARD & API WIRING

بناء لوحة التحكم وربطها بالـ API

من أول نداء Axios إلى رسم بياني يعتمد على بيانات حقيقية

هذا الفصل يحوّل التصميم إلى شاشات تعمل فعلاً. نبني طبقة النداءات مرة واحدة، ثم نربط بها الرفع والجداول والرسوم وتنزيل التقارير. القاعدة الحاكمة: كل رقم يظهر للمستخدم يجب أن يكون قد جاء من استجابة API حقيقية، ولا يوجد رقم مكتوب في الكود.

15.1 عميل الـ API وإعداد الـ Base URL

عميل واحد (api/client.ts) يعرف العنوان الأساسي ويضيف التوكن تلقائياً. العنوان يُقرأ من VITE_API_BASE_URL، فلا نكتب عنواناً داخل أي مكوّن. مصادقة الطلبات تُفعَّل فقط عند VITE_ENABLE_AUTH=true، وهي القيمة المقابلة لـ AUTH_ENABLED في الـ Backend.

frontend/src/api/client.tstypescript
import axios from "axios";

const baseURL = import.meta.env.VITE_API_BASE_URL ?? "http://localhost:8000";
export const AUTH_ENABLED = import.meta.env.VITE_ENABLE_AUTH === "true";

export const api = axios.create({ baseURL, timeout: 30000 });

api.interceptors.request.use((config) => {
  if (AUTH_ENABLED) {
    const token = localStorage.getItem("safevision_token");
    if (token) config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
CORS

المتصفح يمنع الـ Frontend من الاتصال بـ Backend على منفذ مختلف إلا إذا أذن الخادم. لذلك نضع عنوان الواجهة في CORS_ORIGINS على الـ Backend (مثلاً http://localhost:5173). إذا ظهر خطأ CORS فالمشكلة في قائمة الأصول المسموح بها، وليست في كود React.

15.2 طبقة نداءات الفيديو

كل نداءات مورد الفيديو في ملف واحد تعيد الأنواع المطابقة للـ API. هذا يعني أن الصفحات لا تلمس Axios مباشرة، بل تستدعي دوالّ واضحة الأسماء.

frontend/src/api/videos.tstypescript
import { api } from "./client";
import type { JobOut, Paginated, VideoOut } from "../types/api";

export interface VideoListParams {
  page?: number;
  page_size?: number;
  status?: string;
  sort?: string;
}

export async function listVideos(params: VideoListParams = {}) {
  const { data } = await api.get<Paginated<VideoOut>>("/api/v1/videos", { params });
  return data;
}

export async function getVideo(id: string) {
  const { data } = await api.get<VideoOut>(`/api/v1/videos/${id}`);
  return data;
}

export async function uploadVideo(file: File, onProgress?: (p: number) => void) {
  const form = new FormData();
  form.append("file", file);
  const { data } = await api.post<VideoOut>("/api/v1/videos", form, {
    onUploadProgress: (e) => {
      if (onProgress && e.total) onProgress(Math.round((e.loaded / e.total) * 100));
    },
  });
  return data;
}

export async function processVideo(id: string) {
  const { data } = await api.post<JobOut>(`/api/v1/videos/${id}/process`);
  return data;
}

export async function deleteVideo(id: string) {
  await api.delete(`/api/v1/videos/${id}`);
}

15.3 الرفع مع FormData وشريط التقدّم

الرفع يستخدم FormData لأن الـ endpoint يستقبل multipart/form-data. نتحقّق من الامتداد والحجم قبل الإرسال، ونعطّل الزر أثناء الرفع، ونعرض نسبة التقدّم من حدث onUploadProgress. عند النجاح نعيد الفيديو الجديد للصفحة لتحديث الجدول.

frontend/src/features/videos/UploadVideoForm.tsxtsx
import { useState } from "react";
import { uploadVideo } from "../../api/videos";
import type { VideoOut } from "../../types/api";

const ALLOWED = ["mp4", "mov", "avi", "mkv"];

export function UploadVideoForm({ onUploaded }: { onUploaded: (v: VideoOut) => void }) {
  const [progress, setProgress] = useState(0);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function handleFile(file: File) {
    const ext = file.name.split(".").pop()?.toLowerCase() ?? "";
    if (!ALLOWED.includes(ext)) {
      setError("Unsupported video format");
      return;
    }
    setBusy(true);
    setError(null);
    try {
      const video = await uploadVideo(file, setProgress);
      onUploaded(video);
      setProgress(0);
    } catch {
      setError("Upload failed, please retry");
    } finally {
      setBusy(false);
    }
  }

  return (
    <div>
      <input
        type="file"
        accept=".mp4,.mov,.avi,.mkv"
        disabled={busy}
        onChange={(e) => e.target.files?.[0] && handleFile(e.target.files[0])}
      />
      {busy && <progress value={progress} max={100} />}
      {error && <p role="alert">{error}</p>}
    </div>
  );
}

الاستطلاع (polling) يُدار عبر خطّاف عام يوقف نفسه عند انتهاء العمل، ويطبّق تراجعاً بسيطاً عند الخطأ. نستخدمه لمتابعة حالة الـ job بعد بدء المعالجة (تفاصيل أكثر في الفصل 16).

frontend/src/hooks/usePolling.tstypescript
import { useEffect, useRef, useState } from "react";

export function usePolling<T>(
  fetcher: () => Promise<T>,
  options: { intervalMs?: number; enabled?: boolean; shouldStop?: (d: T) => boolean } = {},
) {
  const { intervalMs = 3000, enabled = true, shouldStop } = options;
  const [data, setData] = useState<T | null>(null);
  const [error, setError] = useState<Error | null>(null);
  const [loading, setLoading] = useState(false);
  const timer = useRef<number | null>(null);
  const stopRef = useRef(shouldStop);
  stopRef.current = shouldStop;

  useEffect(() => {
    if (!enabled) return;
    let cancelled = false;
    const tick = async () => {
      try {
        setLoading(true);
        const result = await fetcher();
        if (cancelled) return;
        setData(result);
        setError(null);
        if (!stopRef.current?.(result)) timer.current = window.setTimeout(tick, intervalMs);
      } catch (e) {
        if (cancelled) return;
        setError(e as Error);
        timer.current = window.setTimeout(tick, intervalMs * 2); // simple backoff
      } finally {
        if (!cancelled) setLoading(false);
      }
    };
    tick();
    return () => {
      cancelled = true;
      if (timer.current) window.clearTimeout(timer.current);
    };
  }, [enabled, intervalMs, fetcher]);

  return { data, error, loading };
}

15.5 جدول الوقائع

الجدول يعرض الأعمدة المهمة فقط: النوع، الخطورة، الحالة، وقت البداية، وعدد الكشوفات. كل صف يقود إلى صفحة التفاصيل، ولون الشارة يتبع الـ enum مباشرةً، فلا يوجد لون مخترع.

frontend/src/features/incidents/IncidentTable.tsxtsx
import { Link } from "react-router-dom";
import type { IncidentOut } from "../../types/api";

const severityClass: Record<string, string> = {
  low: "bg-slate-100 text-slate-700",
  medium: "bg-amber-100 text-amber-800",
  high: "bg-orange-100 text-orange-800",
  critical: "bg-red-100 text-red-800",
};

export function IncidentTable({ items }: { items: IncidentOut[] }) {
  if (items.length === 0) return <p>No incidents found for these filters.</p>;
  return (
    <table className="w-full text-sm">
      <thead>
        <tr><th>Type</th><th>Severity</th><th>Status</th><th>Start (s)</th><th>Detections</th></tr>
      </thead>
      <tbody>
        {items.map((it) => (
          <tr key={it.id}>
            <td><Link to={`/incidents/${it.id}`}>{it.incident_type}</Link></td>
            <td><span className={severityClass[it.severity]}>{it.severity}</span></td>
            <td>{it.status}</td>
            <td>{it.started_at_seconds}</td>
            <td>{it.detection_count}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}

15.7 تنزيل تقرير CSV

ملف CSV ليس JSON، لذلك لا نمرّره عبر عميل الـ Axios العادي بالطريقة نفسها؛ نطلب الملف كـ blob ثم ننشئ رابطاً مؤقتاً ونضغط عليه برمجياً. اسم الملف يأتي من الـ header إن وُجد.

frontend/src/features/reports/ExportCsvButton.tsxtsx
import { useState } from "react";
import { api } from "../../api/client";

export function ExportCsvButton({ query }: { query: Record<string, string> }) {
  const [busy, setBusy] = useState(false);

  async function download() {
    setBusy(true);
    try {
      const res = await api.get("/api/v1/reports/export", { params: query, responseType: "blob" });
      const url = URL.createObjectURL(res.data as Blob);
      const a = document.createElement("a");
      a.href = url;
      a.download = "safevision-report.csv";
      a.click();
      URL.revokeObjectURL(url);
    } finally {
      setBusy(false);
    }
  }

  return <button onClick={download} disabled={busy}>{busy ? "..." : "Export CSV"}</button>;
}

خلاصة الفصل 15

ما تعلّمناه

بنينا عميل Axios واحداً يقرأ عنوانه من متغيّر البيئة، وطبقات نداءات لكل مورد، ورفعاً بـ FormData مع تقدّم، وخطّاف استطلاع يوقف نفسه، وجدول وقائع، وبطاقات تحليلات، ورسم Recharts، وتنزيل CSV.

ما يجب تنفيذه

  • ضبط VITE_API_BASE_URL وVITE_ENABLE_AUTH في ملف .env.
  • إضافة عنوان الواجهة إلى CORS_ORIGINS على الـ Backend.
  • ربط كل صفحة بندائها الموحّد بدل استدعاء Axios مباشرة.
  • بناء حالات Loading/Error/Empty لكل قائمة.

المخرجات المتوقعة

  • صفحات تعرض بيانات حقيقية من الـ API.
  • رفع يعمل مع شريط تقدّم ورسائل خطأ عربية.
  • زر تصدير ينزّل ملف CSV فعلياً.

كيف نتحقق من الإنجاز

  • لا يوجد رقم مكتوب في الكود، وكل قيمة تأتي من استجابة.
  • لا يوجد عنوان API داخل أي مكوّن.
  • الاستطلاع يتوقف عند الحالة النهائية ولا يترك مؤقتات تعمل.

أخطاء شائعة

  • كتابة localhost:8000 داخل المكوّن بدل متغيّر البيئة.
  • إرسال JSON بدل FormData في الرفع فيفشل التحقق.
  • نسيان إلغاء المؤقت عند مغادرة الصفحة فيستمر الاستطلاع.
  • معالجة CSV كأنه JSON فيتلف الملف.
